# 酒馆冒险成就

插件在游玩对话结算后按酒馆存档索引中的冒险轮数解锁成就。任一存档达到 100、300、500 或 1000 轮，分别解锁「小有名气」「传奇冒险者」「酒馆传说」和「不朽传说」。

同一个酒馆档案的每档成就只解锁一次。首次启用时，插件根据存档索引补记已达成的档位。新解锁会在当前对话的右下角短暂出现，成就库由新版启动器统一展示。

## 使用

上传插件 ZIP 并按提示重启酒馆。打开「设置 → 酒馆启动器 → 成就库」查看档位、解锁状态和可用的解锁日期。

## 数据

成就保存在酒馆的插件数据目录中，在替换插件或重启后继续保留。记录只包含档位与解锁时间。首次启用前已达成的档位只记录解锁状态。轮数取自酒馆存档索引，沿用原奖牌的统计口径。
