# 酒馆游玩成就

插件在游玩对话结算后按酒馆存档索引中的游玩轮数解锁成就。任一存档达到 100、300、500 或 1000 轮，分别解锁「渐入佳境」「全程高能」「名场面制造机」和「这局直接封神」。

同一个酒馆档案的每档成就只解锁一次。首次启用时，插件根据存档索引补记已达成的档位。新解锁会在屏幕中央弹出成就卡，四档分别配铜色火星、银蓝星芒、金色彩带和虹彩礼花。卡片随后缩向设置入口，可在「设置 → 酒馆启动器 → 成就库」查看。

## 使用

上传插件 ZIP 并按提示重启酒馆。解锁后可以打开「设置 → 酒馆启动器 → 成就库」查看已获得的成就卡牌、档位和解锁日期。

在游玩对话中打开「设置 → 酒馆启动器 → 成就测试」，可手动预览四档弹窗和卡牌。测试卡面显示当前对话的人物卡封面与总字数，预览结束后成就记录保持原样。

## 数据

成就保存在酒馆的插件数据目录中，在替换插件或重启后继续保留。首次解锁时保存人物卡名、封面缩略图、游玩轮数、开始日期和对话总字数。总字数沿用原奖牌的统计口径，统计这段对话里玩家和 AI 的正文。卡面采用原奖牌的排版，缺少人物卡封面时使用双色缎带底图。
