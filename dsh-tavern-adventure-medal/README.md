# 酒馆冒险成就

插件在游玩对话结算后按酒馆存档索引中的冒险轮数解锁成就。任一存档达到 100、300、500 或 1000 轮，分别解锁「小有名气」「传奇冒险者」「酒馆传说」和「不朽传说」。

同一个酒馆档案的每档成就只解锁一次。首次启用时，插件根据存档索引补记已达成的档位。新解锁会在屏幕中央弹出带彩花的成就卡，随后缩向设置入口。成就卡可在「设置 → 酒馆启动器 → 成就库」查看。

## 使用

上传插件 ZIP 并按提示重启酒馆。解锁后可以打开「设置 → 酒馆启动器 → 成就库」查看已获得的成就卡牌、档位和解锁日期。

在游玩对话中打开「设置 → 酒馆启动器 → 成就测试」，可手动预览四档弹窗和卡牌。测试卡面显示当前对话的人物卡封面与总字数，预览结束后成就记录保持原样。

## 数据

成就保存在酒馆的插件数据目录中，在替换插件或重启后继续保留。首次解锁时保存人物卡名、封面缩略图和对话总字数。字数沿用原奖牌「酒馆记忆」的口径，统计这段对话里玩家和 AI 的正文。历史补记的档位使用默认卡面。
